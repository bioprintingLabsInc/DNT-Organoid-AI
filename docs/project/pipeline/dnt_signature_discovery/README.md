## 1. Scientific Objective
To extract sparse, interpretable, cross-study reproducible gene and pathway signatures that reliably distinguish DNT-active compounds from negative reference chemicals across early organoid neurodevelopment.

* **Intended Input**: Model-ready cross-study feature datasets (`data/model_ready/`) + curated DNT labels.
* **Intended Output**: Candidate biomarker gene panels, pathway signature weights, and biological mechanistic interpretations.
