## 1. Scientific Objective
To model co-regulated gene response modules and protein-protein interaction (PPI) network topological features from treatment-induced transcriptional perturbations in human brain organoids.

---

## 2. Intended Inputs & Outputs
* **Intended Input**: Differential expression contrast statistics (`gene_results`) across organoid cohorts + reference human interactome graphs (STRING / BioGRID).
* **Intended Output**: Network perturbation scores, subnetwork centrality metrics, and module eigen-responses.
